### Featured project

**[Drizzl — Inventory & Exception Management](https://github.com/reniwalriona-create/Drizzl-inventory-exception-management-system)**

An inventory and document-reconciliation system built around a beverage company’s operational workflow.

- Connects purchase orders, goods received notices, stock movements, and discrepancies.
- Makes inventory history, shortfalls, and associated financial losses traceable.
- Covers discovery, requirements, data modeling, workflow design, implementation, and validation.

The public repository includes a case study and synthetic demonstration data.
